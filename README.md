# 禾林 RICH ONE 基地分析

桃園青埔「禾林 RICH ONE」雙塔（青商路256–286號）的 3D 基地環境分析簡報，共 15 章：封面、時程、區位、量體、產品、景觀、日照、陰影、風場、視野、天際線、交通、行情、未來、結語。

線上版：https://patrickwang77.github.io/richone-infographic/

操作：← / → 或空白鍵換章，F 全螢幕；三維畫面可拖曳旋轉、滾輪縮放、右鍵平移。網址的 `#` 可直接開某一章，例如 `#wind`、`#market`。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `src/template.html` | 頁面原始碼（版面、three.js 場景、章節文字） |
| `data/scene.json` | OpenStreetMap 建物、道路、公園、軌道與步行路徑（以本案座標為原點，單位公尺） |
| `data/wind.json` | 桃園國際機場 RCTP 2016–2025 逐時風向風速統計 |
| `build.py` | 把資料注入模板，產生 `index.html` |
| `index.html` | 建置結果，GitHub Pages 直接提供此檔 |

修改後重新建置：

```bash
python3 build.py
```

## 資料來源

- 禾林建築官網：基地面積、樓層、坪數、主題公設
- 青埔建案資訊站（痞客邦，2018-05）：戶數、公設比、車位、構造、建築設計、營造
- 591 實價登錄（2026-11-11 更新）：成交筆數、單價、建築完成日
- © OpenStreetMap contributors，資料採 ODbL 授權：建物、道路、公園、軌道
- Iowa Environmental Mesonet：RCTP 逐時觀測
- 經濟日報、工商時報（2025-09-30）：國泰高鐵站前開發

## 說明

本專案為依公開資料整理的獨立分析，並非禾林官方文件。本案量體依 OSM 建物輪廓與衛星影像示意，高度以 1F 4.5 m、標準層 3.3 m 推算；周邊建物高度依類型推估；國泰開發案 5 棟量體僅為示意。
